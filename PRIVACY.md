# Politique de confidentialite - OBS Recording Manager

*Derniere mise a jour : 31 aout 2026*

---

## 1. Qui sommes-nous ?

OBS Recording Manager est un plugin open source gratuit pour OBS Studio, developpe et maintenu par un particulier. Le code source est disponible sur [GitHub](https://github.com/JaysonPasquier/obs-recording-manager).

---

## 2. Donnees collectees

OBS Recording Manager **ne collecte, ne transmet et ne stocke aucune donnee personnelle** sur des serveurs externes.

Le plugin fonctionne entierement en local sur votre ordinateur.

---

## 3. Google Drive - donnees traitees localement

Si vous choisissez d'utiliser la fonctionnalite d'envoi vers Google Drive :

- Un **token d'authentification OAuth 2.0** est obtenu via votre compte Google lors de la connexion. Ce token est stocke **uniquement sur votre ordinateur**, dans le dossier de configuration d'OBS (`%AppData%\obs-studio\plugin_config\obs-recording-manager\settings.ini`).
- Le plugin accede uniquement aux fichiers qu'il a lui-meme crees sur votre Drive (scope `drive.file`). Il ne peut pas lire, modifier ou supprimer d'autres fichiers de votre Google Drive.
- Aucune donnee n'est partagee avec des tiers. Les fichiers envoyes vont directement de votre ordinateur vers votre compte Google Drive.

---

## 4. Fichiers d'enregistrement

Les fichiers d'enregistrement OBS restent sur votre ordinateur (ou dans votre Google Drive si vous activez l'envoi automatique). Le plugin n'a pas acces au contenu des enregistrements, il les deplace ou les envoie uniquement a votre demande.

---

## 5. Aucune publicite, aucun tracking

Le plugin ne contient aucun code de telemetrie, de publicite ou de suivi analytique.
