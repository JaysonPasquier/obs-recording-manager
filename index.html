OBS Recording Manager

Plugin OBS Studio

Gerez vos enregistrements sans quitter OBS

Apres chaque enregistrement, choisissez de garder, supprimer ou envoyer automatiquement vers Google Drive. Interface entierement en francais.

Telecharger le plugin Voir sur GitHub

Fonctionnalites

💬
Dialogue apres enregistrement
Garder, supprimer ou decider plus tard - un choix clair a chaque fois.
🗑️
Trois modes de suppression
Corbeille Windows, dossier temporaire avec delai, ou suppression immediate.
↩️
Annulation rapide
Toast de 10 secondes apres une suppression pour annuler si besoin.
☁️
Envoi vers Google Drive
Connexion OAuth securisee, choix du dossier de destination.

Installation

  1. Telechargez le fichier obs-recording-manager.dll depuis les Releases
  2. Copiez-le dans C:\Program Files\obs-studio\obs-plugins\64bit\
  3. Redemarrez OBS Studio
  4. Acces via Outils > Recording Manager...
OBS Studio 32.x Windows 10 / 11 64 bits
