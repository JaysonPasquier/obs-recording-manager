Confidentialite

Derniere mise a jour : 31 aout 2026

1. Qui sommes-nous

OBS Recording Manager est un plugin open source gratuit pour OBS Studio, developpe et maintenu par un particulier. Le code source est disponible sur GitHub.

2. Donnees collectees

OBS Recording Manager ne collecte, ne transmet et ne stocke aucune donnee personnelle sur des serveurs externes.

Le plugin fonctionne entierement en local sur votre ordinateur.

3. Google Drive

Si vous utilisez la fonctionnalite d'envoi vers Google Drive :

  • Un token OAuth 2.0 est obtenu via votre compte Google. Il est stocke uniquement sur votre ordinateur, dans %AppData%\obs-studio\plugin_config\obs-recording-manager\settings.ini.
  • Le plugin accede uniquement aux fichiers qu'il a lui-meme crees (scope drive.file). Il ne peut pas lire, modifier ou supprimer d'autres fichiers de votre Drive.
  • Aucune donnee n'est partagee avec des tiers. Les fichiers vont directement de votre ordinateur vers votre compte Google Drive.

4. Fichiers d'enregistrement

Les fichiers d'enregistrement OBS restent sur votre ordinateur (ou dans votre Google Drive si vous activez l'envoi automatique). Le plugin ne lit pas le contenu des enregistrements, il les deplace ou les envoie uniquement a votre demande.

5. Aucune publicite, aucun tracking

Le plugin ne contient aucun code de telemetrie, de publicite ou de suivi analytique.

6. Contact

Pour toute question : chardclouzi@gmail.com

7. Modifications

Cette politique peut etre mise a jour. Les modifications sont publiees sur cette page avec la date de mise a jour.
